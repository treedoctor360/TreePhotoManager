# TreePhotoManager

デジカメで撮った樹木診断の写真を、撮影番号と「樹木番号・写真の区分」で記録するスマホ用ページ（試作）。

- 最初にカメラの次のファイル番号を入れ、撮るたびに区分ボタンを押す → 番号が1つずつ進む
- 記録はその端末のブラウザ内だけに保存（サーバーなし）
- 一覧（ファイル・納品用ファイル名・公園・路線・備考）をコピーし、Excelやスプレッドシートに貼り付けて使う

## 更新するとき

`index.html` の `APP_VERSION`（例：`2026-10-15.1`）を毎回変えてから main に反映する。開いている端末に「新しい版があります」と表示され、ボタンで更新できる。
